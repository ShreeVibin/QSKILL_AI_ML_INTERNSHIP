# 📧 Spam Mail Detection using Machine Learning

## Objective

Develop a machine learning model to classify SMS messages as Spam or Ham using Natural Language Processing.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes

## Workflow

- Data Loading
- Data Cleaning
- Label Encoding
- TF-IDF Feature Extraction
- Model Training
- Model Evaluation
- Custom Prediction

## Outcome

Successfully built a spam detection system capable of identifying spam and legitimate messages using machine learning.
